# 업무알리미 (다운로드)

JBEdu 메신저로 받은 업무 쪽지를 **단축키 한 번(Ctrl+Alt+S)**으로 AI가 정리해서,
**[교사도우미](https://teacher-app-2n3.pages.dev/) 앱의 업무 탭에 자동 등록**해 주는 Windows 프로그램입니다.

> 이 프로그램은 **교사도우미와 한 세트**입니다. 정리된 업무는 교사도우미에서 확인·관리합니다.

## 다운로드

오른쪽 **Releases**(또는 아래 링크)에서 `task-notifier.exe` 를 내려받으세요.
👉 **[최신 버전 다운로드](../../releases/latest)**

설치 과정 없이 **더블클릭으로 실행**됩니다. (파이썬 설치 불필요)

## 쓰려면 필요한 것

1. **Windows PC + JBEdu 메신저(Messenger7)** — 전북 지역 학교용 메신저 전용입니다.
2. **교사도우미 앱 사용 + 구글 드라이브 동기화 설정** — 업무가 등록될 곳이에요.
3. **본인 Gemini API 키** — [Google AI Studio](https://aistudio.google.com/)에서 무료로 발급.

## 사용 방법

1. `task-notifier.exe` 를 더블클릭합니다.
2. 처음 실행하면 **설정 창**이 뜹니다. 두 가지를 넣고 "저장하고 시작":
   - Gemini API 키
   - 교사도우미 동기화 주소 (교사도우미 앱 → 백업/동기화 설정의 `...exec?key=...` 주소)
3. 이제 기록하고 싶은 **JBEdu 쪽지창을 보면서 `Ctrl + Alt + S`** 를 누르면,
   화면 오른쪽 아래에 "교사도우미에 등록" 알림이 뜨고 업무가 자동으로 올라갑니다.
4. 교사도우미 앱을 새로고침하면 업무 탭에 나타납니다.

## 참고

- 프로그램은 창 없이 백그라운드에서 돌아갑니다. 종료하려면 작업 관리자에서 `업무알리미` 를 끝내세요.
- Windows SmartScreen 경고가 뜨면 "추가 정보 → 실행"을 눌러 주세요(서명되지 않은 개인 제작 프로그램이라 그렇습니다).
- 문의: 아카이브 제작자에게.
